# CityPass v0.9: road-to-road journey planning

1. Search for a starting road (e.g. Hai Bà Trưng), select the exact map result/segment.
2. In “Bạn muốn đi đâu?”, search for a destination (e.g. Nơ Trang Long) and select the desired segment.
3. Compare candidates generated by CityPass's existing traffic-aware routing API. Up to 5 Open-Meteo estimates are sampled along each route. Weather estimates are NOT on-street measurements and do not model rain during future arrival.
4. Choose a route to preview its polyline on CityPass. Open Google Maps in two-wheeler mode to get turn-by-turn navigation; Google Maps recalculates and cannot guarantee the same path even with up to three via-points.

Safety: If Supabase verified flood reports are not present, routes must say "ngập: chưa có dữ liệu", never "an toàn/không ngập". Existing reported incidents may be stale or pending. Camera imagery has no automated road-condition inference. Routes from OSRM use a driving profile, not motorcycle road restrictions. TomTom motorcycle support depends on account/region and is beta. Do not make claims of verified dry/clear roads.

Keys remain server-side: TOMTOM_API_KEY for search/routing, no new key for Open-Meteo (subject to license/terms and rate limits). Google Maps URLs need no Maps API Key. For production add provider rate-limit/backoff, commercial rights, route freshness monitoring and real flood sensors.
